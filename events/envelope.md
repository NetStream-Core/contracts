# Event envelope

Поля, общие для всех событий агента (`netstream.flow`, `netstream.dns.query`, `netstream.blocklist.hit`). Транспорт — OTLP-логи (см. `kafka/topics.md`); каждое поле ниже — атрибут ресурса или записи лога.

## Идентичность

| Поле | Источник | Тип | Значение |
|---|---|---|---|
| `host.id` | resource-атрибут | string | Идентификатор сенсора; не меняется между перезапусками агента на одной машине |
| `service.instance.id` (`boot_id`) | resource-атрибут | string, hex | Случайное значение, сгенерированное один раз при старте процесса агента; меняется при каждом перезапуске |
| `netstream.event.sequence` | атрибут события | int | Монотонный счётчик от 0, общий для всех типов событий одного `boot_id` |
| `netstream.event.id` | атрибут события | string | `"{boot_id}-{sequence}"` — уникален за всю историю сенсора |

Зачем: Kafka может доставить событие повторно (retry), агент может перезапуститься. `event_id`/`event_sequence` отличают «то же самое событие пришло второй раз» от «это новое событие», а смена `boot_id` в потоке событий одного `host_id` явно показывает точку перезапуска агента.

Реализация не использует отдельный генератор UUID: `event_id` — производное от уже уникальной пары `(boot_id, sequence)`, этого достаточно.

## Время

| Поле | Источник | Значение |
|---|---|---|
| `event_time` | `Timestamp` записи лога | Когда агент сформировал запись — для потока это конец интервала съёма, а не момент прихода конкретного пакета |
| `ingest_time` | колонка ClickHouse, `DEFAULT now()` | Когда строка была вставлена в `otel_logs`; агент это поле не передаёт |

Две оси нужны, чтобы разделить два разных вопроса: «когда это произошло» и «сколько времени телеметрия шла до хранилища» (`ingest_time - event_time`). Без разделения нельзя было бы ответить на вопрос вида «задержка обнаружения — 8 секунд или 800 миллисекунд».

## Где это в коде

- Генерация: `agent/agent/src/telemetry/resource.rs` (`boot_id`), `agent/agent/src/telemetry/logs.rs` (`sequence`, `event_id`, композиция атрибутов события).
- Хранение: `deploy/clickhouse/migrations/014_event_identity.sql` — колонки `boot_id`, `event_sequence`, `event_id`, `ingest_time` на `flows`, `dns_queries`, `blocklist_hits`; `ingest_time` на самом `otel_logs`.
