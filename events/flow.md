# `netstream.flow`

Дельта по одному потоку (пара адресов+портов+транспорт) за один интервал съёма агента (`REPORT_INTERVAL_MS`, по умолчанию 1 с). Несёт общий [envelope](envelope.md).

| Атрибут | Тип | Колонка ClickHouse |
|---|---|---|
| `network.io.direction` | `receive` или `transmit` | `direction` |
| `network.transport` | `tcp`, `udp`, `icmp`, другое | `transport` |
| `source.address`, `destination.address` | IPv4 | `src_ip`, `dst_ip` |
| `source.port`, `destination.port` | int | `src_port`, `dst_port` |
| `netstream.flow.interval_ms` | int | `interval_ms` |
| `netstream.flow.packets` | int | `packets` |
| `netstream.flow.bytes.ip`, `.bytes.payload` | int | `ip_bytes`, `payload_bytes` |
| `netstream.flow.tcp.syn`, `.synack`, `.fin`, `.rst` | int | `tcp_syn`, `tcp_synack`, `tcp_fin`, `tcp_rst` |
| `netstream.flow.aggregated` | 0, 1 или 2 | `aggregated` |
| `netstream.flow.size.le64`, `.le128`, `.le256`, `.le512`, `.le1024`, `.gt1024` | int | `size_le64` … `size_gt1024` |
| `netstream.flow.iat.count`, `.sum_us`, `.sumsq_us` | int | `iat_count`, `iat_sum_us`, `iat_sumsq_us` |

## Признаки формы потока

`size.*` разбивают пакеты интервала на непересекающиеся корзины по полной длине IP-пакета (до 64, 65–128, 129–256, 257–512, 513–1024, свыше 1024 байт). `iat.*` накапливают межпакетные интервалы внутри потока в микросекундах (число интервалов, сумма, сумма квадратов; интервал ограничен 10 с). Среднее и стандартное отклонение считаются на стороне потребителя как `sum / count` и `sqrt(sumsq / count - (sum / count)^2)`. Интервалы измеряются на ядре CPU, обработавшем поток; первый пакет потока в интервале не даёт интервала.

## Порты и агрегация

Порт `0` означает, что агент объединил порт: обычно это эфемерный порт клиента при обычном трафике. Когда исчерпан бюджет новых потоков агента (`FLOW_NEW_PER_SECOND`, флуд с меняющимися портами), пакеты попадают в агрегированные записи:

- `aggregated = 1` — объединён только порт источника (порт назначения сохранён: виден и флуд по одному порту, и сканирование).
- `aggregated = 2` — объединены оба порта.

Суммы пакетов и байт при агрегации сохраняются полностью, не теряются.

## Известные особенности

`synack_ratio` (производный признак, не сырой атрибут — см. `ml/src/netstream_ml/features.py`) считается внутри окна одного `src_ip` и показывает долю **собственных** SYN-пакетов источника, которые сами являются SYN-ACK — то есть насколько источник ведёт себя как принимающая сторона соединений, а не проверку «дошли ли ответы на мои SYN»: ответ на SYN от другого хоста попадает в окно того хоста, а не в окно инициатора. У атакующего источника это значение почти всегда ≈0 — это не признак того, что флуд не дошёл до цели.
